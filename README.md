## Key Features

* Config options - Allows for changes to speed, fps, and sizes.

## Usage

* Ensure you have the required packages listed below installed.
* In OBS, place an Image source in a scene.
* In dvd_bounce_config.json, set the source_name, scene_name, and dimensions accordingly.
* From your terminal, navigate to the programs directory.
* run python DVD_Bounce.py
